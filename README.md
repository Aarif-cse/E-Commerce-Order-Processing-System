# E-Commerce Order Processing System

## Operating Systems PBL Project

**Course:** Operating Systems (CCSE0303A)  
**Institution:** NIET Greater Noida  
**Team:** Group 04  
**Project:** E-Commerce Order Processing System

## Overview

This project demonstrates how Operating Systems concepts can be applied to an e-commerce order-processing workflow. It models order management, CPU scheduling, synchronization of shared resources, producer-consumer coordination, and deadlock avoidance using Python.

## Features

- Process management and order-state transitions
- FCFS, SJF, Priority, and Round Robin CPU scheduling
- Priority ageing to reduce starvation
- Binary semaphore for safe inventory updates
- Producer-consumer synchronization using a bounded buffer
- Counting semaphore for limited packing stations
- Banker’s Algorithm for deadlock avoidance
- Test output for evaluating scheduling and synchronization

## Technologies Used

- Python
- Python threading and synchronization primitives
- Operating Systems concepts

## How to Run
  
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python order_processing_final.py
```

Follow the script's available options and output to inspect the demonstrations.

## Project Scope

This is an academic prototype using sample data. It is intended to demonstrate Operating Systems concepts and is not a production e-commerce platform.
